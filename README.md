# أثر — ما ينفعك ويبقى أثره

موقع إسلامي هادئ يجمع القرآن الكريم والأذكار والأدعية في مكان واحد، بلا حسابات ولا إعلانات، ويُحسب عدد الزيارات فقط دون بيانات شخصية.

- القرآن الكريم: نص Tanzil، بخط مجمع الملك فهد (KFGQPC Uthmanic Script HAFS)، ومعنى الآيات من التفسير الميسر.
- الأذكار والأدعية: من «حصن المسلم»، ومن الصحيحين والسنن مما صحّحه الألباني، وأدعية القرآن والأنبياء من نص المصحف.
- يعمل دون اتصال بعد أول زيارة، ويمكن تثبيته على الجوال.

مصادر المحتوى وتراخيصها مذكورة في صفحة «المزيد» داخل الموقع، وترخيص خط المصحف في `LICENSE-KFGQPC.txt`.
